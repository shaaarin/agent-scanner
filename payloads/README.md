# Внешние наборы payload'ов

Каталоги подключаются read-only в сканеры (`EXTRA_PAYLOADS_DIR=/payloads`) и
читаются **на лету**: чтобы добавить свои или сторонние payload'ы, положите
сюда YAML-файл и создайте новое сканирование — пересобирать образ не нужно.

- `indirect/` — инъекции в результаты инструментов (`scanner-indirect`).
  Формат записи: `name`, `family`, `mode` (`append`/`prepend`/`replace`),
  `template` с плейсхолдерами `{{canary}}` и `{{tool_name}}`.
- `sysleak/` — атакующие промпты для утечки системного промпта
  (`scanner-sysleak`). Формат: `name`, `family`, `prompt` (плейсхолдеры не
  нужны — метку вставляет прокси в системное сообщение).

Имя (`name`) уникально: набор из этого каталога **переопределяет** встроенный
payload с тем же именем — так штатный payload можно заменить своим.

**Обязательно оставляйте `{{canary}}` в шаблонах инъекций** — на метке держится
детектирование: сканер ищет её в ответе агента.

Формат и шкала оценки — `docs/reports.md`, устройство сканеров —
`docs/architecture.md` §7.3 и §7.4.
